# Third-party icons and images

Where the icons and pictures in `app/src/main/res` come from. Each vector drawable also names its
source in a comment on its first lines.

## One UI icon pack (MIT)

The One UI icon pack ([`@thatjoshguy/oneui-icons`](https://www.npmjs.com/package/@thatjoshguy/oneui-icons)
on npm) is MIT licensed: see [ONEUI-ICONS-LICENSE](ONEUI-ICONS-LICENSE). Any icon from the pack added to
this app is covered by that licence and must keep it.

**No icon in the app currently comes from this pack**, so the licence does not cover any of the
files listed below.
